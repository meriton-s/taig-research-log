- maybe it’s worth doing a small project on user behavior changes following ai deployment
- feels like the kind of thing that could be approached with causal inference tools — like pearl-style causal graphs. otherwise why did i study it
- but what kind of behavior am i even talking about? that’s a massive space — and data might be hard to get
- need to narrow the question way down
- maybe pick one platform and track something like comment tone or posting frequency?no — that’s starting from what’s easy to measure, not from what i actually need to know
- so what’s the hypothesis?
→ that ai systems are now embedded deeply enough into digital platforms that we should start seeing stacked behavioral effects — small local shifts adding up to visible social change

- what kind of patterns would count?
→ not just one user changing behavior — but system-wide changes that build over time
→ if those don’t show up, maybe ai hasn’t meaningfully touched that domain yet

- could it be that ai doesn’t cause these changes at all?
→ sure. maybe its influence is still within the range of normal meme dynamics — nothing new under the sun
→ in that case, i’d expect to see no strong deviation in user behavior vs past years
→ but that’s what causal inference is for — to untangle that mess (or at least try)
→ so yeah, maybe that’s the actual project: **trace stacked user behavior shifts and see if we can link them to ai deployment events** 

- so where should i look?
→ places where ai has been embedded the longest → more time to shift the baseline
→ places where ai has the strongest influence → less human filtering, easier to spot patterns
→ places where the stakes are actually high → it’s more important to notice changes in public health sentiment than in laundry detergent preferences
