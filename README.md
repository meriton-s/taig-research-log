# taig-research-log

This is my pet-project research log and code repository (maybe — if I end up doing some evals again =).  
I'm trying to get a better feel for the field of Technical AI Governance (TAIG), and maybe do something useful along the way.

## Plan

- Read overview papers and a few related things  
  → summaries and notes go in `log/dist-*` and `log/readlist.md`

- Pick out problems that seem interesting, impactful if solved, and reasonably tractable  
  → reflections and updates go in daily logs (`log/YYYY-MM-DD.md`)

- Sketch some project ideas  
  → rough outlines and drafts go in `log/ideas.md` or new `log/project-*.md` files

- Hopefully find a mentor to talk to  
  → udates and thoughts also go in daily logs (`log/2025-mm-dd.md`)
